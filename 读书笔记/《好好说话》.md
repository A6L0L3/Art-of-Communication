# 《好好说话》·五维话术实战笔记
> 一句话主旨：说话不是天赋，是一套技术活。每一句话都是一场权力游戏，取胜的关键不是说得漂亮，而是先认出这是哪种游戏，再选对打法。

## 板块0 · README
### 0_1 这份笔记解决什么问题
大多数讲沟通的书，要么教你"说话要温柔"，要么教你"说话要强势"。这两类建议都有用，但都无法解释一件事：为什么同一句话，在这个场合有效，换一个场合就失效。

原书的核心贡献，是把"会说话"这件玄学拆成了五个可识别、可练习的维度，并给出大量"错误说法与正确说法"的对照。

这份笔记做的是三件事：

**第一，让你能快速判断眼下的场景属于哪一维。** 这是全书最有用的一步，也是多数人跳过的一步。判断错了，后面所有的招式都是反效果。

**第二，把每个维度的招式拆成"底层逻辑 + 说法模板 + 适用边界"。** 只背句式而不理解原理，换个场景就会用错。每条技巧都标注了为什么有效、什么时候别用。

**第三，配上练习方法和验证口径。** 让话术从看过变成会用。

**一句必须写在最前面的提醒。** 原书强调，话术的价值在于修正三观、激发思维，而不在于背下标准答案。同一句话换个场合就失效，所以这份笔记的每条技巧都标了边界。

### 0_3 三个必须接受的前提
原书的序言部分讲了三条前提，它们决定了这份笔记里所有技巧的适用范围。

**前提一，说话之伤都是暗伤。** 说错话的代价往往不会当场结算，而是累积在关系里。别人不会告诉你"你那句话很伤人"，只会慢慢疏远你。所以要主动建立反馈回路，见 8_2。

**前提二，说话的底气来自实力。** 原书很诚实地指出，话术不是万能的。没有内容支撑的话术，说到底是花架子。如果你的方案质量不过关，再漂亮的表达也只能换来一次机会。

**前提三，好好说话其实是好好思考。** 大部分说错话的情况，不是措辞问题，而是没想清楚：你要什么、对方要什么、这件事谁说了算。想清楚了，措辞往往自然就对了。

### 0_4 笔记记录方法
话术类内容的笔记方式与知识类完全不同：**不要抄金句，要抄"场景 + 我原来的说法 + 改法 + 用后的结果"**。

**推荐用五栏话术卡：**

```latex
【话术卡】
场景（谁对谁、什么事）：
维度（沟通、说服、谈判、演讲、辩论）：
我原来的说法：
改后的说法：
为什么改（底层逻辑）：
用后的实际结果：
```

**三条补充的记录习惯：**

**录音复盘法。** 重要沟通后回听三分钟，只找一处最想改的地方。不要贪多，一次改一处。

**错话本。** 专门记自己说砸的话，比记金句有用十倍。每记一条，写一句下次怎么说。错话本的威力在于重复识别：当你发现同一类错误出现三次，那就是你的系统性短板。

**场景归档。** 把话术卡按五维分类归档，你会慢慢看出自己最弱的是哪一维。多数人会发现自己只会一维，其余四维都在用同一套打法硬撑。

### 0_5 效果验证：三个可检验的口径
| 口径 | 怎么测 | 说明 |
| --- | --- | --- |
| 返工率 | 同一件事需要重说几次才被理解 | 反映表达结构是否清晰 |
| 对抗度 | 对话中对方出现几次防御性回应，包括反驳、沉默、反问你什么意思 | 反映维度判断是否错位 |
| 达成率 | 一个月内主动发起的沟通有多少拿到了想要的结果 | 综合验证 |


**最灵敏的是对抗度。** 如果你发现自己总在解释"我不是那个意思"，基本可以断定维度用错了。最常见的错配是该沟通时用了辩论。

**三个口径的判读：**

+ 返工率下降，说明表达结构改善了，对应板块5_5 与 8_4。
+ 对抗度下降，说明维度判断改善了，对应板块1_2。
+ 达成率上升，说明你不只是说得好听，而是说到了点上。

如果三项都没变，问题多半不在话术，而在实力与信息——回到 0_3 的前提二。

### 0_6 三份笔记如何搭配
这份笔记解决的是"同一件事用哪种打法"的问题。三份笔记各管一段：

| 笔记 | 解决什么 | 何时用 |
| --- | --- | --- |
| 五维话术笔记（本笔记） | 用沟通、说服、谈判、演讲还是辩论 | 决定我该用哪种打法 |
| 内向者4P笔记 | 要不要出场、怎么出场、出场后怎么恢复 | 决定我该不该做这件事 |
| 身体语言笔记 | 对方没说出口的部分怎么读、自己怎么发信号 | 决定现场怎么微调 |


**组合顺序：先判维度，再定出场方式，现场用身体信号微调。**

举例：你要向上司争取一笔预算。先用五维判断这是说服（权力在对方）；再用 4P 准备（写清对方能得到什么、准备三个可能的问题）；现场观察上司的身体信号（后仰说明抗拒，前倾说明有兴趣），随时调整。

## 板块1 · 每句话都是权力的游戏
这是全书的地基。不读懂这一章，后面五个维度就只是五个分类，而不是五套打法。

### 1_1 五维模型：先认出游戏类型
原书的立论是：说者和听者总会构成某种关系，而特定关系中总存在谁主动谁被动、谁需要争取谁的问题，这就是权力关系。

**你需要影响谁的观念，谁就掌握着这场语言游戏的权力。**

| 维度 | 权力关系 | 核心目标 | 典型场景 |
| --- | --- | --- | --- |
| 沟通 | 权力在双方，是流动的 | 让信息无损流动，避免冲撞与误解 | 安慰、道歉、日常交谈、协作 |
| 说服 | 权力在对方 | 改变对方的想法与决定 | 提案、推销、让老板批方案 |
| 谈判 | 权力在双方 | 协调利益，在合作中争取己方利益最大化 | 讨价还价、薪资、资源分配 |
| 演讲 | 权力的形成，落在听众 | 吸引、聚焦、打动，赢得大多数 | 汇报、路演、公开讲话 |
| 辩论 | 权力在他方，由第三方裁决 | 通过对抗争取中立第三方支持 | 方案论证、观点交锋、危机回应 |


**一句话记法：**

```latex
  沟通 = 权力的流动    平等交换信息
  说服 = 权力在对方    我没权，要改变有权的人
  谈判 = 权力在双方    都要合作才能解决
  演讲 = 权力的形成    我要聚起权力
  辩论 = 权力在他方    胜负由第三方判
```

### 1_2 五种权力关系的详解
**沟通：权力的流动。**

双方地位对等，权力在你来我往中流转。目标是让信息在双方之间无损交换。

为什么叫"流动"？因为沟通中的主导权会不断易手：你说一段，我接一段，谁在说谁暂时占主导。所以沟通的核心技巧是"接得住"，而不是"说得赢"。

**说服：权力在对方。**

决定权在对方手里，你没有权，却要改变有权的人。所以说服的本质不是讲道理，而是改变对方的立场结构：让他觉得这个决定对他有利。

**谈判：权力在双方。**

双方各有一部分权力，任何一方单独都解决不了问题，必须合作。所以谈判的目标是"在合作中争取己方利益最大化"，而不是压倒对方。

**演讲：权力的形成。**

你原本没有权力，要从听众那里聚起来。所以演讲的核心是吸引与聚焦：先让人愿意听，再让人认同。

**辩论：权力在他方。**

胜负不由双方决定，而由中立第三方裁决。所以辩论的目标从来不是说服对手，而是争取旁观者。

### 1_3 维度用错的代价
原书有个生动的比喻，值得完整记住：

```latex
  只学沟通  ->  像兔子，柔弱，谁也推不动
  只学说服  ->  像狐狸，腹黑，让人防备
  只学谈判  ->  像鳄鱼，冷酷，没有温度
  只学演讲  ->  像孔雀，显摆，华而不实
  只学辩论  ->  像刺猬，难缠，处处扎人
```

真正的会说话，是在五种模式间自如切换。

**三类最常见的错配：**

| 错配 | 典型表现 | 后果 |
| --- | --- | --- |
| 该沟通时用了辩论 | 和伴侣吵架拼命证明自己对他错 | 赢了道理，输了关系 |
| 该说服时用了演讲 | 向老板提加薪时滔滔不绝讲自己的辛苦 | 老板觉得你在邀功 |
| 该谈判时用了沟通 | 谈价格时先掏心掏肺讲难处 | 对方拿你的难处当筹码 |


**为什么"该沟通时用了辩论"最致命。** 因为亲密关系和长期协作关系里没有第三方裁判。辩论的设计目标是争取旁观者，而家里没有旁观者，所以辩论的胜负机制在那里失效，只剩下伤害。

### 1_4 三秒判断法（现场判断口诀）
**第一问，这件事谁说了算。**

+ 对方说了算，是说服。
+ 双方共同决定，是谈判。
+ 第三方裁决，是辩论。

**第二问，我的目的是交换信息还是改变对方。**

+ 交换信息，是沟通。
+ 改变对方，是说服或谈判。

**第三问，我在对一个人说还是对一群人说。**

+ 对一群人说，是演讲。

**三问的判断顺序不能变。** 先问谁说了算，因为它决定了整个打法。很多人一上来就纠结措辞，而措辞是最不重要的一层。

**一个进阶判断。** 有些场景是复合的：比如部门会上的汇报，形式上是对一群人说（演讲），实质上是要老板批预算（说服）。此时以实质目标为准，也就是按说服来设计，但用演讲的技巧来呈现。

### 1_5 话术能力是全息的
原书强调话术能力是"全息的"，意思是：五个维度不是五个独立技能，而是同一套能力在不同权力结构下的表现。

**这个观点的两个实际含义：**

**含义一，短板会拖垮长板。** 你沟通很强但说服很弱，结果就是大家喜欢你但不会听你的。反过来，你辩论很强但沟通很弱，结果就是没人愿意跟你聊第二次。

**含义二，进步是整体的。** 练表达结构（结论前置）会同时提升五个维度的表现；练倾听会同时改善沟通与说服。所以训练要打底层能力，不要只在某一维上堆技巧。

### 1_6 案例小故事：同一件事的三种打法
**背景。** 小周想让上司批一笔三万的培训预算。他试了三次，前两次失败，第三次成功。

**第一次，误用演讲。** 他准备了一份二十页的材料，在部门会上讲了十五分钟行业趋势和学习型组织的重要性。讲完上司说：挺好，先放着。结果无下文。

**为什么失败。** 他把这件事当成了"展示自己有想法"，而实际上他要的是"一个人做出一个决定"。十五分钟的趋势讲解，对那个决定毫无帮助，反而增加了上司的决策成本。

**第二次，误用沟通。** 他私下找上司说：最近感觉团队能力跟不上，我很焦虑。上司说：大家都焦虑。结果被当成情绪倾诉。

**为什么失败。** 沟通维度的目标是交换信息、获得理解，而上司接收到的确实只是"他状态不好"。他想要的是改变对方的决定，那是说服，不是沟通。

**第三次，用对说服。** 他说了这段话：

> 上次项目延期的根因是新人上手慢，平均六周。这笔培训能把上手周期压到三周，相当于每个项目省出两周。我做了两个方案，方案 A 三万，方案 B 内部带教八千但要多花两个月。我建议方案 A。
>

结果当场拿到批复。

**为什么成功。** 三个要素齐全。

第一，他认出了这是说服，权力在对方，于是把"我想要"翻译成了"你会得到什么"。

第二，他给了具体的收益换算：六周压到三周，每个项目省两周。抽象的"提升能力"无法被决策，具体的数字可以。

第三，他给了两个方案并给出建议，把决策成本降到了最低。上司只需要说"同意"或"选 B"。

**一句话总结。** 差别不在口才，而在他认出了这是哪种游戏。

> 记录与验证：回想最近三次没说成的沟通，逐个标注你当时用的是哪一维、正确的应该是哪一维。把结果写进话术卡。三次里如果有两次判断错误，说明你的问题不在表达，而在判断。

## 板块2 · 沟通：让权力在双方之间流动
沟通的关键词是权力流动，目标是让信息无损交换、避免冲撞与误解。原书强调：沟通不是要说服对方，而是将双方置于同一平面。

### 2_1 承上启下的工具性沟通：买时间
当你需要时间组织思路时，不要沉默硬扛。原书给出的结构是三段：

```latex
  制造意外  ->  引发好奇  ->  回应主题
```

| 场景 | 说法 |
| --- | --- |
| 被突然点名发言 | 这个问题有点复杂，我想先说结论 |
| 需要一分钟整理 | 请给我一分钟好吗，我想把这件事讲清楚 |
| 局势紧迫必须长话短说 | 这事儿很复杂，但你想先听结论还是先听背景 |


**要点。** 买时间不是拖延，而是把"我还没想好"翻译成"我在为你组织一个更好的答案"。

这个翻译很重要，因为沉默会被解读成能力不足或态度消极，而"我在组织"会被解读成认真。

**一个补充技巧。** 买时间时可以配合一个具体动作：拿出笔、打开笔记本、把椅子往前挪。这些动作会强化"我在认真处理"的信号。

### 2_2 传递坏消息：专业、善意、陪伴
原书指出一个反直觉的点：遇到坏事，人总想找个负责人，而且这个人越近越好。

所以**不要主动把责任往自己身上揽**，比如一开口就说对不起。否则你的身份会从传达者变成要负责的行动方。

**三步法：**

```latex
  第一步，专业：直接说明事实，不铺垫，不含糊
  第二步，善意：表达遗憾，说我很遗憾，而不是说对不起
  第三步，陪伴：给出可提供的信息与后续安排
```

**说法模板：**

> 我来说明一下情况。很遗憾，情况并不乐观。有任何疑问都可以问我，我会告诉你我所知道的一切。
>

**为什么区分"遗憾"与"对不起"。** 对不起是责任声明，遗憾是情感表达。在传递坏消息的场景里，你要表达的是情感，而不是承担责任。混淆这两者，会让后续的沟通变得极其被动。

**三个常见的错误做法：**

1. 过度铺垫："你先别激动啊"——这句话本身就会让人激动。
2. 模糊事实："可能有点问题"——模糊会让人反复追问，最终更痛苦。
3. 抢着安慰："别难过"——你不是来安慰的，你是来传递信息的，安慰会让你承担不该承担的角色。

### 2_3 初次见面：聊名字，不聊隐私
破冰的原则是不给对方压力、不索取信息。聊名字是最安全也最有效的入口，因为每个人都希望自己是独特的。

**错误说法。** 我认识一个人也叫这个名字。这句话把对方变回普通人，好处瞬间消失。

**正确说法。** 这个名字很少见，家里应该挺有讲究吧，点名的时候是不是总被读错。

**禁区清单。** 收入、婚恋状况、年龄、健康状况、政治观点、生育计划。这些话题无论关系多好，初次见面都不应触及。

**为什么聊名字有效。** 因为它满足了一个人最底层的需求：被看见独特性。而且它不需要对方透露任何敏感信息，心理成本极低。

### 2_4 拉近距离：分享态度，而不是索取信息
想用轻松话题拉近距离，正确姿势是抛砖引玉：先分享自己的态度或一个小糗事，再抛给对方。

**三条规则：**

1. 不索取信息，只分享态度。
2. 用开放性问题，且把问题抛给在场所有人，不单独逼问某一个人。
3. 自我揭短必须是真话，且不能是抱怨。

**说法模板：**

> 我觉得找工作还是得找自己喜欢的，你觉得呢，你喜欢你现在的工作吗。
>

**为什么"抛给所有人"很重要。** 单独逼问一个人会形成压力，而抛给所有人之后，任何人都可以选择不接。给对方退路，才是真正的礼貌。

**为什么自我揭短不能是抱怨。** 抱怨会把气氛拉低，而且会让对方觉得你在寻求安慰，而不是在交流。揭短要带幽默感，抱怨带的是负能量。

### 2_5 委婉拒绝：先问原因，不先问数量
以借钱为例，这个结构适用于所有被索取的场景。

| 步骤 | 做法 |
| --- | --- |
| 第一步，问原因 | 你最近是遇到什么困难了（救急的情况可以直接给红包，不必走流程） |
| 第二步，表达共同处境 | 我也刚遇到类似的问题 |
| 第三步，说明边界 | 借钱这事我确实帮不上，真抱歉 |


**核心原理。** 拒绝的对象是这个请求，不是这个人。先问原因，既给了对方解释空间，也让你判断这件事的真实紧急程度。

**为什么先问原因比直接拒绝好。** 因为直接拒绝会让对方觉得被否定，而问原因传递的是关心。同样是拒绝，一个让人记恨，一个让人感激。

**一个变体。** 如果你确实想帮但能力有限，可以在第三步给出替代：我借不了这么多，但我可以借你两千，不用还。把"拒绝请求"变成"提供另一个帮助"，对方更容易接受。

### 2_6 人际冲突预防：打感受的预防针
原书提醒：冲突中要意识到两个版本的存在，你的版本和对方的版本都是真实的。

**预防冲突的办法是在事前铺垫三步：**

```latex
  第一步，铺垫：抱歉，这或许未必是事实，但
  第二步，用自身缺点表达真实感受：你知道我这人有点较劲
  第三步，明确这是你的感受，不是指控
```

**为什么需要预防针。** 因为同一句话，在对方没有心理准备时是攻击，在有准备时是提醒。预防针的作用是把攻击降级为提醒。

**预防针的三种形式：**

| 形式 | 说法 |
| --- | --- |
| 事实不确定型 | 这或许未必是事实，但我看到的情形是 |
| 自身缺点型 | 你知道我这人有点较劲，所以我想说 |
| 感受归属型 | 这可能是我多想了，但我的感受是 |


### 2_7 承认自身情绪，引导他人情绪
沟通中最大的误区是处理情绪的方式错误。

| 场景 | 常见错误 | 正确做法 |
| --- | --- | --- |
| 自己的情绪 | 压抑、装没事 | 察觉，小幅释放，提前预告 |
| 别人的情绪 | 反驳、说你先冷静一下、闭嘴 | 隔离，同理，拦截 |


**处理自己的情绪：不要等到爆发才说。** 小幅释放更有效：

> 再这样我可要生气了。  
我不开心，需要听你说两句好话。  
天大的事等我消气了再说。
>

提前预告给了对方调整的机会，也给了自己台阶。它的本质是：用语言在情绪爆发前设置一个缓冲带。

**处理他人情绪的三个动作：**

**隔离。** 先防住自己的情绪被带走：我理解你很急，我们先把事实列出来。

**同理。** 承认对方的感受，但不同意指控：换我我也会上火。注意，同理的是情绪，不是观点。

**拦截。** 面对人身攻击，拦截而不是反击：

> 关于这一点，我觉得你不应该这样说，不过这不是重点，我们还是来研究一下解决方案。
>

**拦截的关键。** 不接对方扔过来的情绪球，把球带回事情本身。反击会升级冲突，拦截会转移战场。

### 2_8 自我沟通：把弱点当铠甲
原书有一节专门讲这个。掩盖弱点有两个风险：暴露后的心理成本极高，而且会让别人越来越好奇你真实的弱点。

**正确做法是主动、有选择地暴露，三条规则：**

1. 自嘲的弱点应该是对方已经可能知道的弱点。
2. 不要和盘托出，暴露的是无关紧要的弱点。
3. 用自嘲与自谦进行自我保护。

**原理。** 适度暴露弱点会显著提升可信度。一个承认自己数学不好的人说"这个数据我算过三遍"，反而更可信。

**争取他人信任时，多暴露无关紧要的弱点，是低成本高回报的做法。**

**三个可以直接用的自嘲句式：**

> 我这人方向感特别差，所以这份路线图我标得特别细。  
我记性不好，所以每次开会我都记笔记，你们要哪次的内容我都能翻出来。  
我不太会说话，那我就直接说重点。
>

第三个句式最有价值：它把不会说话这个弱点，转换成了"我会说实话"这个优势。

### 2_9 幽默：讲笑话不等于幽默
**三条规矩：**

**内容上，错位反差是关键。** 幽默的本质是预期被打破。铺垫一个方向，然后在最后一刻转向另一个方向。

**语气上，不要自己先笑。** 自己先笑会破梗，因为幽默需要听众自己完成那个"发现"的瞬间。

**角度上，避免误伤。** 有比你更处于弱势的人在场时，不要用这个点自嘲。你的自嘲会把那个人的处境也变成笑点。

**一条重要提醒。** 玩笑不一定要好笑，幽默感有时锦上添花，无也无伤大雅。不要把"讲笑话"当成必修课，那不是幽默。

### 2_10 道歉：蚂蚁搬大象
原书给了一个很有画面感的说法：道歉的时候，要尽可能把责任往自己身上揽，甚至到夸张的程度。

**完整结构：**

```latex
  关闭过去 = 明确承认错误 + 明确造成的伤害
  承诺未来 = 给出补救方案 + 给出预防措施
```

**错误示范。** 对不起，但这事也不全怪我。道歉里带转折，等于没道歉，而且比不道歉更糟，因为它同时表达了敷衍和不甘。

**正确示范。**

> 这件事是我的疏忽，我应该在周三之前就同步给你，结果让你在会上被问住了，这是我的责任。我现在把数据补给你，接下来的每周三我会固定同步一次，不会再出现这种情况。
>

**分寸提醒。** 尽可能往自己身上揽，适用于你确实有责任、且对方需要的是态度的场景。不适用于责任尚未查明、或涉及法律责任认定的场景。

### 2_11 安慰与批评：焦点放在哪里
**安慰。**

错误说法：别难过了，都会过去的。这句话否定对方的情绪。

错误说法：我理解你。你其实不理解，说了就是敷衍。

正确做法：表明在场、提供具体帮助、不抢责任。

> 我也不知道该说什么，但我今晚都在，需要我做什么你说。
>

**批评。**

错误说法：你这人怎么总是这样。这是攻击人格，对方会立刻进入防御。

正确做法：把行为与人格分开，把评价换成感受。

> 你这样做让我有点为难。我认为你做得很好，只不过这件事上，我们下次能不能先对一下口径。
>

### 2_12 案例小故事：一次没有升级的投诉
**背景。** 客服主管小陈接到了一个愤怒的电话。客户的产品在保修期内坏了，已经来回沟通三轮没解决，第四次打来时情绪激动，开口就是威胁投诉到监管部门。

**小陈的第一反应。** 她最初想说的是：先生您先别激动，这个情况我们需要走流程。这是最常见的说法，也几乎每次都会让客户更激动。

**她实际做的三步。**

**第一步，隔离自己的情绪。** 她先在心里提醒自己：他骂的是这件事，不是我。这一步只花两秒，但决定了后面所有反应。

**第二步，同理加复述。**

> 换了我在保修期内坏了东西，来回跑了三轮还没解决，我也会生气。我确认一下，您是说三轮沟通里，每轮都有人承诺回复但都没回，对吗。
>

客户说：对，就是这个。

**第三步，陪伴加具体承诺。**

> 很遗憾这件事拖了这么久。我现在能做的是两件：今天下午六点前给您一个明确的检测结论；如果检测确定是质量问题，我直接走换新流程，不用您再申请。您看这样可以吗。
>

**结果。** 客户的音量在第二步就降下来了，第三步之后说：那我等你六点的电话。投诉没有发生。

**机制拆解。** 三个要点。

第一，她没有说"别激动"，而是承认了情绪的合理性。"别激动"是在否定情绪，"换我也会生气"是在肯定情绪。

第二，她用了复述确认，把客户的情绪宣泄转成了事实清单。一旦变成事实清单，就有了解决的抓手。

第三，她给的是具体承诺，带时间点、带流程承诺。模糊的"我们会尽快处理"无法安抚，具体的"今天六点前"可以。

**可复制的顺序。** 隔离、同理、复述、具体承诺。这四步适用于所有情绪化的沟通场景，且都不需要口才。

> 记录与验证：本周挑一次自己的情绪做小幅释放，用提前预告句式，比如"再这样我可要生气了"。记录对方的反应与事后关系的温度变化。多数人会发现，预告之后对方的调整速度超出预期。
>

## 板块3 · 说服：把观点装进对方心里
说服的关键词是**权力在对方**。你没有权，却要改变有权的人。所以说服的核心不是讲道理，而是改变对方的立场结构。

### 3_1 用选择权启发对方
原书指出：动不动就说教是说服的头号杀手。"你为什么不这样做"这种问法会让对方进入辩护模式。

**反直觉的技巧是反问：**

| 类型 | 说法 |
| --- | --- |
| 错误 | 你为什么不去做 |
| 正确 | 你不应该会这样啊，那你觉得应该怎么做 |
| 进阶 | 你曾经有那么一点点想做吗 |
| 进阶 | 你居然会想这么做，我很好奇 |


**原理。** 让对方自己说出你想让他说的话。人对自己得出的结论有更强的执行意愿，因为没有人喜欢被说服，但所有人都喜欢自己想通。

**使用注意。** 反问的语气要真诚好奇，不能带嘲讽。同样一句"你居然会想这么做"，用好奇的语气是启发，用冷笑的语气是攻击。

### 3_2 诉诸需求，而不是道理
说服的落点永远是对方的需求，不是你的道理。

**三个步骤：**

```latex
  第一步，找到对方能听进去的理由，用他的视角
  第二步，找到他感同身受的痛点
  第三步，给一套完整的解决方案
```

**对不同对象的落点不同：**

| 对象 | 落点 |
| --- | --- |
| 上级 | 规避风险，而不是强调创意 |
| 客户 | 他当下的痛点，而不是你的产品优势 |
| 同伴 | 他能得到什么，而不是这件事多重要 |


**为什么对上级要落点在规避风险。** 因为上级的决策目标函数是"不出事"优先于"出彩"。强调创意会让他想到不确定性，强调风险规避会让他想到安全感。

### 3_3 创造压力，改变双方立场
这是全书中有杀伤力的一招：当双方立场僵持时，引入第三方压力，把你和对方从对立变成共同面对。

```latex
  主观对立：我觉得应该改，你觉得不该改
  引入压力：我们这样做，监管、预算、时间方面的压力会很大啊
```

**两个常用工具：**

**工具一，塑造共同的敌人。** 把问题外化：我们这样做的话，某方面的压力会很大。注意多说"我们"。

**工具二，营造机不可失的时间紧迫感。** 我很希望继续讨论，但因为时间紧急我必须离开，所以可以先这样处理吗。

**一个变体：给人戴高帽子。** 把人架起来：你眼光这么好，不会看不出这里的好处吧。

注意帽子不能太高也不能太低，否则失去真实感，反而显得在讽刺。

### 3_4 说服年长、地位高的人
**误区：输出价值观是没有意义的。** 你无法用三分钟改变一个人三十年的价值观。

**正确做法是用对方的视角看问题。** 找他能听进去的理由，找他感同身受的痛点，给完整方案。

**说法模板：**

> 您总教我某件事很重要。但在这件事上，情况是这样的。您可能不太清楚，其实我也是没有办法。
>

**结构拆解。** 先承接对方的价值观，降低防御；再摆出事实缺口，提供新信息；最后把结论留给他自己得出。

**为什么不能省略第一步。** 直接摆事实会被解读成挑战：你在暗示他不知道。先承接，则把"我不知道"变成了"你之前不知道这个新情况"。

### 3_5 说服比你专业的人
**两个误区：** 用感受评价专业，比如"我觉得这个颜色不对"；用命令逼迫服从。

**正确三步：**

```latex
  第一步，克制直接表达主观感受的冲动，少说我觉得
  第二步，提出抽象需求，而不是具体要求，让专业的人选择实现方式
  第三步，不命令，在探讨中达成共识
```

**说法模板。** 你觉得这个方案怎么样，你能不能提供一个新的方案。

**为什么"抽象需求"有效。** 因为专业人士最反感的是外行指定实现方式。你告诉他要什么结果，他会自己找到更好的实现路径；你告诉他怎么做，他只会照做，而且做出来往往不如他自己设计的。

### 3_6 催促老板：不扮可怜，不求人
**三招叠加：**

```latex
  第一招，真诚表示体谅，低阻力开场：您最近这么忙，应付得过来吗
  第二招，提供后备方案，清空焦虑内存：您要是没时间处理，方案 B 怎么样
  第三招，点明短期收益，刺激动力：如果您能抽出时间处理，我们能拿到什么
```

**原理。** 老板拖延通常不是不想办，而是焦虑内存被占满。你替他清空内存，也就是给后备方案，并给出即时收益，他就动了。

**为什么不能扮可怜。** 扮可怜是在用自己的处境施压，会让对方产生内疚，而内疚驱动的行动质量最差，且会损害长期关系。

### 3_7 请人帮忙：诉求具体、善意扩大、给选择
| 要素 | 做法 |
| --- | --- |
| 诉求具体 | 说清要什么、什么时候、需要多长时间 |
| 善意扩大 | 让对方知道这件事对他的意义 |
| 给选择 | 让对方能说不，反而更容易说是 |


**完整示例。**

> 我想请你帮我看这份方案的结构，大概需要二十分钟。你今天下午或者明天早上方便吗。如果都忙也没关系，我找别的办法。
>

最后一句是关键：给出退路之后，对方答应你的概率反而上升，因为压力消失了。

### 3_8 朋友犯浑：别追问原因
**三个错误：追问为什么、独善其身、拼命阻拦。**

**正确三步：**

```latex
  第一步，不问为什么，问怎么了：到底怎么了，谁得罪我家哥哥
  第二步，引导情绪宣泄，你要比你朋友更狠一点
  第三步，与其阻拦，不如把计划落到实处：去，当然要去，我们来合计合计
```

**为什么"更狠一点"有效。** 因为人在情绪中需要的是被认同，而不是被劝。你比他更狠，他反而会自己开始找理由降温，因为有人替他骂了，他就不需要再骂了。

**边界。** 如果对方要跨底线，你必须明确表态：

> 我永远当你是朋友，但你这样是陷我于不义，那就没有我这个朋友吧。
>

### 3_9 说服不进取的人
**原理是降低对方对结果的恐惧。** 用可能性代替目标性，营造意愿而不是下指令。

**三个句式：**

> 就算没做成，也不会怎么样啊。  
我觉得你可以做很多事，未必要像他那样。  
这样也挺有意思嘛。
>

**为什么有效。** 不进取的人通常不是懒，而是怕失败后的评价。把"你要做到某件事"改成"试试看会怎样"，恐惧就消失了。

### 3_10 案例小故事：把一个不可能的需求说成共识
**背景。** 设计师小唐想让研发配合做一批视觉优化，研发负责人一口回绝：没价值，排不上。

**第一次，说教。** 小唐说：视觉一致性很重要，用户会感知到的。对方回：有数据吗。失败。

**失败原因。** 他在输出自己的价值判断，而对方要的是证据。价值判断无法被反驳也无法被接受，它只会引发"那又怎样"的回应。

**第二次，他换了两件事。**

**第一件，他先去收集信息。** 他翻了上季度的客诉记录，发现有十七条跟界面混乱有关，其中六条被写进了复盘报告。

**第二件，他用对方的视角重述。**

> 我看了上季度的客诉，有十七条跟界面混乱有关，其中六条被写进了复盘。这批优化做完，下季度这类客诉大概率能砍掉一半，到时候复盘会上这算是你们的一个亮点。我这边已经把改动清单压缩到十二个页面，你看看哪几个可以插进这次迭代。
>

**结果。** 对方说：给我看看清单。事情进入了执行。

**机制拆解。** 三个转变。

**转变一，从讲道理到讲收益。** 第一次讲的是"视觉一致性很重要"，这是他的道理；第二次讲的是"客诉下降、复盘亮点"，这是对方的收益。

**转变二，从要不要做到做哪几个。** 这是用选择权启发对方的典型应用。一旦问题变成"做哪几个"，默认前提就已经是"要做"了。

**转变三，他把工作量压缩到了可评估的单位。** 十二个页面是可评估的，"一批优化"是不可评估的。

**可复制的三步。** 说服失败时，不要加强语气，而是去补三样东西：对方的痛点数据、对方的收益换算、一个可以被拆解成小单位的工作量。

> 记录与验证：下次说服前，先写下一句话：对方真正在意的是什么。如果写不出来，说明你还停留在自己的道理里，先去做信息收集，参考 4_1 的情报搜集方法。
>

## 板块4 · 谈判：把冲突变成合作
谈判的关键词是**权力在双方**。双方必须合作才能解决问题，所以目标是在合作中争取己方利益最大化，而不是压倒对方。

### 4_1 开局：旁敲侧击地搜集情报
谈判前的信息决定谈判中的底气。三个低成本的打探问题：

```latex
  第一问：您是怎么知道我们的        （摸清对方的来路与备选）
  第二问：这方面，你们之前做过最大的案子是多少  （摸清对方的量级与预算区间）
  第三问：按这样的条件，我给您推荐别家好不好    （试探对方的诚意与紧迫度）
```

**第三问尤其好用。** 它是一个假意让步的探针，对方的反应会直接暴露他的备选情况：犹豫说明有备选但不满意，拒绝说明他认准了你，接受说明你不是他的首选。

**为什么要在开局问。** 因为一旦进入实质议价，双方都会开始隐藏信息。开局阶段的氛围最松，信息最容易流出。

### 4_2 纠正式引导：故意犯错让对方纠正
这是获取信息的高效技巧，利用的是对方想纠正你的心理。

**三步：**

```latex
  第一步，故意说一个略带偏差的说法：我听说你们去年做了某个项目，对吧
  第二步，语气用轻微的刺激或激将，但不要过度：我就知道不会有别的可能了
  第三步，对方一纠正，就把信息缺口再扩大一点，继续追问
```

**原理。** 人在纠正别人时会放松警惕，因为注意力在"纠正错误"上，而不是在"保守秘密"上。信息就在纠正中流出来了。

**注意分寸。** 偏差不能太大，否则显得你不专业；语气不能过激，否则对方会觉得被冒犯。最安全的幅度是"差一点点"，比如把金额说低一档、把年份说晚一年。

### 4_3 出价：突破惯性思维与定锚效应
| 技巧 | 说明 | 注意 |
| --- | --- | --- |
| 定锚 | 先出价者设定区间，可适当开出高价 | 锚要有理由支撑，否则失去可信度 |
| 确认标准 | 用标准获取主动权，常用于谈薪资 | 先问这个岗位的定级标准是什么 |
| 断崖式还价 | 还价一次到位、幅度大、只还一次 | 不要反复小幅加价，那会暴露底线 |


**谈加薪的正确顺序，可整段套用：**

```latex
  第一步，确认标准：我想了解一下，这个职级的薪资区间和定级标准是怎样的
  第二步，大方讨论表现：用事实和结果，不用辛苦和情绪
  第三步，定锚：给出你的期望数字，并说明依据，是市场、贡献还是职责扩大
  第四步，谈非现金项：若现金空间有限，转向培训、项目、职级、弹性
```

**为什么第一步要问标准。** 因为标准一旦被确认，后面的讨论就有了共同参照系。不问标准直接报价，对方只会用他的内部标准来压你。

**为什么第二步不能用辛苦。** 辛苦是成本，不是价值。老板为价值付钱，不为辛苦付钱。说"我加了三个月班"，对方的反应是"那效率是不是有问题"。

### 4_4 让步：在让步中谈成交易
让步不是单方面退让，而是交换。

**三条原则：**

1. 每一次让步都要换回一个东西：我可以接受这个价格，但交付周期要放宽到某个天数。
2. 让步幅度递减：第一次大、第二次小，让对方感到到底了。
3. 让对方也为成交付出一点，他才会珍惜这个结果。

**第三条最容易被忽略。** 一个完全不承担代价的成交，对方反悔的概率更高。让他也让一步，是在增加他的沉没成本，从而增加交易的稳定性。

### 4_5 僵局：不如搁置
谈不下去时，最差的选项是硬压。正确做法是搁置并检查：

```latex
  第一步，明确搁置，不撕破脸：这个点我们今天可能谈不下来，先放着
  第二步，回到共同利益：我们双方的共同目标是
  第三步，换一个维度谈：价格不行谈交付，交付不行谈范围
  第四步，设定再谈的时间点
```

**为什么"换维度"经常有效。** 因为价格是一个零和维度，你多我就少；而交付时间、服务范围、付款节奏这些维度可以创造增量。一维谈不下去，就开第二维。

### 4_6 辞职怎么说
**三要素：**

1. **告知去处。** 有下家就说，增加确定性，也避免挽留拉扯。
2. **慎选理由。** 用文化不合适、性格不合这类中性表述，不评价具体的人。
3. **表示感激。** 行业很小，收尾质量决定你的口碑。

**为什么理由要中性。** 因为真实理由往往是对某个人或某件事的不满，说出来会留下攻击性的印象，而这个印象会被传播。中性理由保护的是你自己。

### 4_7 案例小故事：一次没有降价的降价
**背景。** 供应商要求涨价百分之十五。采购小郑不能直接接受，因为超预算；也不想换供应商，因为切换成本高。

**她的判断。** 这是谈判，不是说服。双方都需要对方，所以有谈的空间；但价格这一维上她的空间很小。

**她没有讨价还价，而是问了三句。**

第一句：这次涨价的主要成本项是哪一块。对方说是原材料。

第二句：原材料涨了多久了，你们之前有锁价吗。这一句暴露出对方锁了三个月的价格，说明涨价的紧迫性没有对方说的那么高。

第三句：如果我们把付款周期从六十天缩到三十天，价格能到多少。

**结果。** 最终成交：涨价百分之六，付款周期从六十天缩到三十天，另外拿到了优先排产权。

**机制拆解。** 三个要点。

第一，她先用提问拿到了信息（成本结构、锁价情况），而不是在价格上硬碰硬。

第二，她引入了新维度。价格谈不动，就谈付款周期——对小郑来说账期是成本，对供应商来说账期是现金流，而现金流对供应商的价值高于对采购方的价值。这就是典型的非对称价值交换。

第三，她顺手要了优先排产权，这是一个几乎零成本的附加项，但价值不低。谈判的最后阶段，顺手要一个附加项是常见做法，因为此时对方的成交意愿最强。

**可复制的做法。** 当价格谈不动时，列出除了价格还能交换的三样东西：账期、交付周期、服务范围、排他条款、优先权、联合宣传。选一个对对方价值高、对自己成本低的项目来换。

> 记录与验证：下次谈判前列出三样东西：对方的备选、我的备选、除了价格还能交换的两项。谈完核对实际交换了哪几项。如果你一次谈判只谈了价格，说明你的维度开得不够。
>

## 板块5 · 演讲：靠语言的力量赢得好感
演讲的关键词是**权力的形成**。你要从听众那里聚起影响力。原书强调：演讲形式看似最简单，但要克服的障碍最多。

### 5_1 别紧张，没人在意你的尴尬
这是全书对演讲最反直觉也最有用的一条：

```latex
  结巴了，继续讲
  忘词了，即兴发挥
  出了错，过了就过了，不要回望和纠结
```

**原理。** 观众并不期待你完美，他们期待你有内容。你在台上对自己的苛责，观众根本没注意到。

这个现象叫聚光灯效应：人们会高估自己的失误在他人眼中的显著程度。实际测量结果是，你记住的失误数量，通常远超听众能回忆的数量。

**配套的自信训练三招：**

**第一招，练习失误。** 事先准备一个跟忘词、口误有关的小笑话，真出错时用得上。

**第二招，设定收听率。** 只在意百分之八十的人，放弃那百分之二十不看好的。

**第三招，正向解读。** 比如"刚才那个像我点头的姑娘，肯定是明白了"。

### 5_2 建立信任：先降预期，再露真材实料
听众的信任决定演讲的成败。两个反直觉技巧：

```latex
  技巧一，适当降低听众的预期
          开场不要说：我今天要讲一个划时代的东西
  技巧二，漫不经心地吐露真材实料
          比如：刚才那不过是开场，有那么一个人，不确定大家认不认识，
          当年他也曾经跟我说过一句话
```

**原理。** 高预期加普通内容等于失望，低预期加硬内容等于惊喜。而漫不经心地展示资历，比正儿八经地自我介绍更有冲击力，因为它显得不费力。

**三个降低预期的开场方式：**

| 方式 | 说法 |
| --- | --- |
| 缩小范围 | 今天不讲大道理，就讲一件上周发生的小事 |
| 自谦难度 | 这个问题我想了很久也没想明白，今天算是汇报思考过程 |
| 降低形式感 | 我不太会演讲，那我就直接讲了 |


### 5_3 照顾到多方面的微妙关系
听众不是一个人，是多个群体。三种顺应：

| 顺应 | 含义 |
| --- | --- |
| 权力顺应 | 内容要让场合里权力最高的人不尴尬 |
| 阶层顺应 | 让不同层级的人都能找到自己的利益点 |
| 多数顺应 | 照顾大多数人的认知水平，不要只为最懂的人讲 |


**权力顺应的具体做法。** 如果你的方案会暴露某位在场领导此前的决策失误，就换一种表述，把失误归因于当时的信息条件，而不是归因于人。

**多数顺应的常见错误。** 为照顾最懂的百分之十，把内容讲到那十个人才跟得上的深度，结果百分之九十的人离场。正确的做法是把深度放在可延后讨论的部分，主线上保持大众能懂。

### 5_4 众口难调与大家不想听时的发言
当听众明显不感兴趣时，三步处理：

```latex
  第一步，点破尴尬：直接承认我知道大家现在有点累，反而能拉回注意力
  第二步，明确主题：一句话说清今天要讲什么，跟他有什么关系
  第三步，找对听众：讲给那个真正需要听的人
```

**为什么"点破尴尬"有效。** 因为尴尬是房间里所有人都知道但没人说的事，一旦有人说破，紧张感就消失了。这是最便宜的破冰方式。

**第三步的价值。** 如果全场只有一个人需要听你的内容，那就讲给他听。这种情况在汇报中很常见，而很多人会因为"其他人没反应"而乱了阵脚。

### 5_5 清晰表达与避免啰嗦
| 技巧 | 做法 |
| --- | --- |
| 关键信息多角度重复 | 同一个观点用三种方式说一遍：结论、例子、数据 |
| 难懂处主动留白 | 用对不对、你懂我意思吗这类确认语，给听众消化时间 |
| 复杂观念操作性表述 | 把抽象概念变成动作或步骤 |
| 先问再答 | 先确认意图和方向，再展开 |
| 看人下菜碟 | 同一内容对不同对象换包装 |
| 先讲中心句 | 结论前置，再给论据 |


**为什么"复杂观念要操作性表述"。** 因为抽象概念在听众脑中无法落地。说"我们要提升协同效率"，听众没有画面；说"以后跨部门需求统一走一个入口，三天内必须给回复"，听众立刻知道要做什么。

### 5_6 三种特殊演讲
| 类型 | 要点 |
| --- | --- |
| 胜选演讲 | 忽略胜利、关照众人、赞美对手；弥合分歧，把我变成我们；感谢盟友 |
| 败选演讲 | 优雅地表现不服，我输了但我没错，你赢是侥幸；感谢盟友；澄清误解、重塑形象 |
| 内向者的演讲形象 | 自嘲，建立信任（告诉大家真实情况），以小见大（从自身小事出发，不要假装别人）；准备必须充分 |


**胜选演讲为什么要先忽略胜利。** 因为胜利时刻台下有一半人是你的对手方。先关照众人、赞美对手，是在做弥合；一上来庆祝，是在制造分裂。

**败选演讲为什么不能彻底认输。** 因为彻底认输会让你失去未来的位置。优雅地表现不服，是在为下一次保留空间，同时给支持者一个交代。

**内向者做演讲的一条重要提醒。** 不要假装自己是别人。你的优势是可信和克制，那就走"以小见大"的路：从一个真实的、小的自身经历切入，比模仿激情派演讲有效得多。

### 5_7 案例小故事：忘词之后的那十秒
**背景。** 新人小何第一次做部门汇报，讲到第三页就忘词了。幻灯片停在那里，全场安静。

**第一次的处理。** 她的第一反应是道歉：对不起我有点紧张。然后更紧张，后面全程照着幻灯片念完，效果很差。

**为什么道歉会更糟。** 因为道歉把一次小失误放大成了一个事件，提醒所有人"这里出错了"。如果不提，大部分人根本不会注意。

**第二次的准备。** 她准备了一句备用句：这句话我准备了三个版本，现在一个都想不起来，那我说人话。

**第二次的现场。** 果然又卡住了。她说了这句，底下笑了一声，气氛松了，她顺着讲完了。

**结果。** 会后领导的评价是：比上次自然多了。

**机制拆解。** 三个要点。

第一，观众记住的不是你的失误，而是你失误之后的表现。处理方式本身就是内容的一部分，一个好的处理甚至能加分。

第二，她把失误变成了幽默素材，用的是错位反差：我准备了三个版本却都想不起来，这本身就是一个自嘲。

第三，她用"那我说人话"完成了切换，从背稿模式切到说话模式，后面反而更自然。

**可复制的做法。** 任何公开表达前，准备一句失误备用句。备用句的三个标准：短、能自嘲、能自然接回正题。

> 记录与验证：下次公开表达前，准备一句失误备用句。讲完后记录两件事：你记住的失误有几处；请一位听众回忆，他能说出几处。两者的差距就是聚光灯效应的证据，把它记下来，下次紧张时拿出来看。
>

## 板块6 · 辩论：通过对抗争取第三方支持
辩论的关键词是**权力在他方**，胜负由中立第三方裁决。所以辩论的目标从来不是说服对手，而是争取旁观者。

原书把它称作必要的心智防身术：在充斥着忽悠的世界里让你保持清醒。

### 6_1 准确地意识到对方存在的问题
**三个基础动作：**

```latex
  动作一，复述问题：把对方的问题原样复述一遍，让对方和第三方自己觉得这个问题有多奇怪
  动作二，慢而不断：语速放慢、语气不断，不纠结于口头争辩
  动作三，化繁为简：把对方绕来绕去的论证压缩成一句话
```

**复述问题是成本最低、杀伤力最大的一招。** 很多问题一经准确复述，本身就站不住了。

**为什么"慢而不断"重要。** 因为辩论中语速快的一方会显得急躁，而急躁会削弱可信度。慢，是掌控感的直接体现。

### 6_2 反驳是辩论的核心能力
**反驳的标准结构，四步：**

```latex
  第一步，复述对方观点，确认靶子
  第二步，指出问题：事实错、逻辑错、前提错、偷换概念，四选一
  第三步，给出替代解释
  第四步，点明对第三方意味着什么
```

**第四步是辩论区别于吵架的地方。** 辩论的一切都要落到"这对旁观者意味着什么"。只完成前三步，你只是在和对手纠缠。

**四种错误的识别方法：**

| 错误类型 | 特征 | 反驳的话术 |
| --- | --- | --- |
| 事实错 | 引用的数字或时间不对 | 这个数据的出处是哪里，我看到的口径不同 |
| 逻辑错 | 因果不成立或推论跳跃 | 从这一步到那一步，中间少了什么 |
| 前提错 | 整段论证建立在一个不成立的前提上 | 你这个说法的前提是某件事，但那件事不成立 |
| 偷换概念 | 同一个词在论证中换了含义 | 你前后用了两次这个词，两次的意思不一样 |


### 6_3 借力打力，以退为进
面对玩笑式嘲讽或恶意提问，直接翻脸或默默忍受都不是好选项。策略是借力打力：顺着对方的话，把力量引到别处。

| 攻击类型 | 应对 |
| --- | --- |
| 玩笑式嘲讽 | 顺着笑点接一句，然后转向正题 |
| 陷阱问题，二选一 | 先发现意图，再指责动机：你这个问题预设了什么 |
| 流氓思路，不讲道理只讲输赢 | 三段式：我在讲道理，不是讲输赢；如果讲输赢，那你已经输了；嫌我认真，我就要更认真 |


**一句万能缓冲句。** 都听您的，万一走错了，总不好让您负责吧。

这句话是三分真七分假，作用是把决策成本还给对方，让对方自己掂量。

### 6_4 拒绝上级的不合理安排
这是辩论思维在职场最实用的一次迁移。三步：

```latex
  第一步，战略上高度肯定：这个方向我完全认同
  第二步，成本上精密核算：按现在的资源，要做到这个标准需要多少人天、多少预算、牺牲什么
  第三步，决策权完全上交：所以我想请您定，是加资源、降标准，还是延时间
```

**原理。** 你不是在拒绝，而是在把决策的代价完整地呈现给有决策权的人。

**为什么第一步不能省。** 因为省略第一步会让对方觉得你在对抗，而有了第一步，后面所有的成本核算都变成了"为了更好地实现这个方向"。

**为什么第三步要给三个选项。** 因为两个选项容易形成对立（做或不做），三个选项则把话题拉到"怎么做"上，而"怎么做"是可以讨论的。

### 6_5 辩论的使用边界
**亲密关系里慎用。** 家里不是法庭，没有第三方裁判，赢了也是输。

**需要长期协作的场合慎用。** 辩论会留下对抗记忆，而协作关系里的对抗记忆成本很高。

**用它来防身而不是进攻。** 原书对辩论的定位是心智防身术，主要用于拆解别人的忽悠，而不是用来赢过身边的人。

**一个自检问题。** 这次争论结束之后，你还需要和对方长期共事吗。如果需要，就把辩论降级成沟通或谈判。

### 6_6 案例小故事：一句话拆掉一个伪两难
**背景。** 项目复盘会上，有人提出一个问题：这次延期，要么是我们执行不力，要么是客户需求变太多，你觉得是哪个。

**这是个典型的陷阱问题。** 它把复杂情况压缩成了两个选项，而两个选项都指向"有人要负责"。无论被问者选哪个，都会得罪一方。

**被问者的应对。** 他没有二选一，而是说了这段话：

> 这个问题预设了只有两种可能。我补充第三种：需求变更流程里没有变更代价的评估环节，所以任何变更都能零成本进来。这才是延期的根因。
>

**结果。** 会上一度安静，然后话题转向了流程。后来团队真的加设了变更评估环节。

**机制拆解。** 三个要点。

第一，他先指出预设，而不是直接回答。这是应对陷阱问题的标准动作：先解构问题，再回答问题。

第二，他提供的第三种解释既有归因又不指向具体的人，所以不会得罪任何一方。在有多方在场的场合，这个特性极其重要。

第三，他改变了第三方看问题的框架。主持人和其他与会者此后讨论的是流程，而不是责任。这就是辩论的真正战果。

**可复制的话术结构。** 当遇到二选一的陷阱问题时：这个问题预设了只有两种可能，我补充第三种，然后给出第三种，最后说明这一种对大家都意味着什么。

> 记录与验证：本周遇到一次带有预设的问题时，练习先复述对方的预设，再指出它。记录对方的反应是承认、转移还是加码。加码说明对方有意为之，此时改用 6_3 的指责动机法。
>

## 板块7 · 场景速查手册
按场景查，每条给出：错误说法、为什么错、怎么说、属于哪一维。这一章可以单独打印或收藏。

### 7_1 道歉
**错误说法。** 这事我们也有难处，希望您理解。这是把道歉变成了辩解。

**原理。** 道歉等于关闭过去加承诺未来，顺序不能颠倒，也不能只做一半。

**怎么说。**

```latex
  关闭过去：明确承认错误，明确造成的伤害，把责任尽可能往自己身上揽
  承诺未来：给出补救方案，加预防措施
```

**速查示例，对客户场景。** 货期晚了三天是我们的责任，没有借口。这三天让您的门店少了陈列，损失我来承担。今天下午我安排顺丰补发，以后每单出货前我给您发一次确认单，不会再出现这种情况。

**维度。** 沟通。

### 7_2 安慰
**错误说法一。** 想开点，这不算什么大事。这是否定对方情绪的严重程度。

**错误说法二。** 我懂你的感受。你其实不懂，说了就是敷衍。

**怎么说。** 表明在场、提供具体帮助、不抢责任。

**速查示例。** 这事我帮不上什么忙，但我可以陪你去办手续，明天上午我有空。你需要的话我十点过来接你。

**维度。** 沟通。

### 7_3 批评
**错误说法。** 你做事一直不靠谱。这是攻击人格，对方会立刻进入防御。

**怎么说。** 把行为与人格分开，把评价换成感受。

**速查示例。** 这次的交付时间我是到了会上才知道的，这让我很难安排后面的工作。你的专业判断我一直很认可，只是下次能不能提前一天告诉我，我这边就能避开冲突。

**维度。** 沟通。

### 7_4 赞美
**错误说法。** 你真厉害。空泛的赞美不可信。

**怎么说。** 具体，且与对方的自我认知一致。

> 你刚才那个追问把客户真实需求挖出来了，这一步很关键。
>

**原理。** 具体的赞美才能被相信，且能引导对方重复这个行为。

**维度。** 沟通或说服。

### 7_5 求助
**错误说法。** 能不能帮个忙。模糊，对方无法评估成本，只能含糊答应或含糊拒绝。

**怎么说。** 诉求具体、善意扩大、给选择，三要素缺一不可。

**速查示例。** 想请你帮我看两页文案，大概十分钟。你看完能告诉我哪里读着别扭就行，这稿子明天要对外发。今晚或者明早都行，你哪个时间方便。

**维度。** 说服。

### 7_6 催办
**错误说法。** 那个事您处理了吗。暗示对方失职，会让对方防御。

**怎么说。** 体谅加后备方案加短期收益，三招叠加，详见 3_6。

**速查示例。** 这块我一直等着反馈，是不是我给的材料还不够清楚。我再补一页对比表给您，您看完直接告诉我要方案 A 还是方案 B 就行。

**维度。** 说服。

### 7_7 拒绝
**错误说法。** 不行。或者说我考虑考虑，后者更糟，因为拖延会抬高对方的期待。

**怎么说。** 先问原因，再给边界。拒绝请求，不拒绝人。

**速查示例，拒绝不合理的时间要求。** 我理解这件事很急。按现在手上的两个硬交付，我周五才能给出完整版。如果你要得快，我今天先出一版简版给你应应急，完整版周五补上，你看行吗。

**维度。** 沟通。

### 7_8 回应挑衅
**错误做法。** 回骂，或者沉默忍受。

**怎么说。** 拦截而非反击，不接对方扔过来的情绪球。

**速查示例。** 你这句话我先不接，因为接了我们就跑题了。回到刚才那个问题，你觉得两个方案哪个更可行。

**维度。** 沟通，必要时用辩论。

### 7_9 谈薪资
**四步顺序。** 确认标准、谈表现、定锚、谈非现金项，完整展开见 4_3。

**速查示例。** 我想先了解一下公司对这个职级的定级标准，这样我谈数字也有依据。过去一年我带的项目里，有两个是超额完成的。我期望的区间是某个数字到某个数字，主要依据是职责比入职时扩大了两块。如果现金这块空间有限，我想聊聊职级和项目机会。

**维度。** 谈判。

### 7_10 即兴发言
```latex
  第一步，买时间：这个问题有点复杂，我想先说结论
  第二步，只讲一个观点
  第三步，配一个具体例子
  第四步，收尾回到听众：这也是为什么在座的各位
```

**维度。** 演讲。

### 7_11 传递坏消息
**原则。** 专业、善意、陪伴三件套，详见 2_2。不要说对不起，要说很遗憾。

**速查示例。** 我直接说结果：这次的审批没有通过。很遗憾，我也没想到。我把评审意见整理成三条发给你，需要的话这周我可以陪你重新过一遍材料。

**维度。** 沟通。

### 7_12 拒绝上级的不合理安排
**三步结构。** 战略上高度肯定，成本上精密核算，决策权完全上交，展开见 6_4。

**速查示例。** 这个方向我认同，问题在时间。按现在两个人手，周五交完整版意味着测试只能做一半。我列了三个选项：加一个人、把测试范围缩小到核心流程、或者延到下周二交完整版。您看哪个合适。

**维度。** 辩论或谈判。

### 7_13 初次见面破冰
**错误说法。** 我认识一个人也叫这个名字，或者说你看起来很年轻。前者消解独特性，后者是评价。

**怎么说。** 聊名字，不聊隐私，不给对方压力。

**速查示例。** 你这个名字是哪几个字，我想确认一下写法。很少见，是家里有讲究吗。

**维度。** 沟通。

### 7_14 说服比自己专业的人
**错误说法。** 我觉得这个颜色不对。用感受评价专业，会触发对方的专业防御。

**怎么说。** 抽象需求，不指定实现方式，完整三步见 3_5。

**速查示例。** 我在意的是用户第一眼能不能找到入口，这个目标现在达到了吗。如果没有，你觉得用什么方式更好，你来定实现方式。

**维度。** 说服。

> 记录与验证：从上面十四条里挑三条你最常用错的，写进错话本，每条配一句改后的说法，本周内各用一次。
>

## 板块8 · 话术训练法：从看过到会用
看完整本书，最常见的结局是"说得好有道理"，然后一切照旧。这一章解决的是转化问题。

### 8_1 三遍改写法（核心训练）
对任何一句你想改的话，做三遍改写：

```latex
  原句：
  第一遍，换立场：如果我是对方，我希望听到什么
  第二遍，换维度：这件事真正的维度是什么，沟通、说服、谈判、演讲还是辩论
  第三遍，换结构：结论前置了吗，有没有给对方选择权
```

**完整示例：**

```latex
  原句：这个需求做不了。

  第一遍，换立场：这个需求现在做不了，但我知道它对你很重要。

  第二遍，换维度，其实是谈判：
  这个需求现在做不了。如果放在下个迭代，我可以做完整版；
  如果这次必须上，我只能做核心流程。

  第三遍，换结构：
  结论是这次只能上核心流程。两个选项，要么这次上核心、下迭代补完整，
  要么整体延到下迭代。你选哪个。
```

**为什么这个练习有效。** 因为它强制你走完三个视角，而平时我们只会站在自己的视角说一次就完事。

**练习频率。** 每天一条，五分钟。练习素材可以是你当天说过的一句话，也可以是书中任意一句。

### 8_2 录音复盘法
| 步骤 | 做法 |
| --- | --- |
| 准备 | 重要沟通前确认可否录音，或只做自我复述录音 |
| 回听 | 只听三分钟，找一处最想改的地方，不要贪多 |
| 记录 | 写进话术卡，标注下次怎么说 |
| 再练 | 把改后的说法出声讲两遍 |


**关注三个具体指标：**

1. **语速。** 紧张时会加快。判断标准是每分钟字数，正常讲话约每分钟两百字，超过两百五十就偏快。
2. **填充词。** 那个、就是说、然后的密度。
3. **句子长度。** 超过三行的句子听众记不住。

**一条提醒。** 听自己的录音很不舒服，这是正常的。几乎所有人都觉得自己的声音陌生，但这个不适感会在听第三次之后消失。

### 8_3 角色扮演与压力预演
找一个练习伙伴，做三轮：

```latex
  第一轮，正常版：对方配合
  第二轮，刁难版：对方故意打断、质疑
  第三轮，沉默版：对方不回应，逼你把话说完整
```

**第三轮最容易被忽略也最有用。** 它训练的是在没有反馈的情况下保持结构的能力。

现实中，沉默是最常见的压力场景：你说完一段，对方没有任何反应。此时多数人会开始补充、解释、重复，把自己的论点稀释掉。沉默版练习专门用于对抗这个倾向。

### 8_4 结构模板库（表达时直接套）
| 模板 | 结构 | 适用 |
| --- | --- | --- |
| PREP | 观点、理由、例子、观点 | 表达立场、即兴发言 |
| SCQA | 情境、冲突、问题、答案 | 汇报、提案 |
| 关闭加承诺 | 承认、补救、预防 | 道歉、事故说明 |
| 三选项 | 结论、A 与 B 与 C、建议、请对方定 | 向上汇报、拒绝不合理安排 |


**PREP 示例。**

> 观点：我建议把这个功能延后一个迭代。  
理由：现在的核心流程还有三个已知缺陷没有解决。  
例子：上周的测试里，其中两个缺陷导致了数据不一致。  
观点：所以我建议延后一个迭代，先把核心流程修完。
>

**SCQA 示例。**

> 情境：我们的用户留存率连续两个季度持平。  
冲突：但获客成本同期上升了三成。  
问题：花更多钱买来的用户留不住，这个模型能撑多久。  
答案：我建议把下一季度预算的三成从获客转到留存。
>

### 8_5 错话本（最有价值的个人资产）
```latex
【错话本】
日期、对象、维度：
我说的（原话）：
对方反应：
为什么错（底层逻辑）：
下次怎么说：
```

**每周翻一次错话本。** 重复出现的错误才是真问题。

比如你发现自己经常"道歉里带转折"，那就是你的系统性短板，要专门练一周。识别系统性问题的方法是分类统计：把错话按类型分堆，最大的那堆就是你的短板。

**错话本的三种分类维度：**

| 分类 | 说明 |
| --- | --- |
| 按维度分 | 沟通错、说服错、谈判错、演讲错、辩论错 |
| 按错误类型分 | 结论后置、只说感受、选项太多、防御姿态 |
| 按对象分 | 对上级、对平级、对下属、对客户、对家人 |


三种分类各统计一次，你会得到三个不同的短板，取交集处的那个，就是最该练的。

### 8_6 案例小故事：三遍改写救回的一次需求沟通
**背景。** 产品经理小梁收到业务方一个紧急需求，要求本周上线。他评估后做不了，第一次回复被对方顶了回来。

**第一次的说法。** 这个需求做不了，本周排满了。

**对方的反应。** 那你想想办法，业务那边等不了。

**他用三遍改写法重做。**

**第一遍，换立场。** 他站在业务方角度想：对方要的不是"本周上线"，而是"本周给客户一个交代"。于是他改成：这个需求本周上不了线，但我知道你需要给客户一个说法。

**第二遍，换维度。** 他意识到这不是沟通，是谈判——双方都需要对方，且可以交换。于是他改成：完整版本周上不了，但如果只上核心流程，我可以排进去。

**第三遍，换结构。** 结论前置加两个选项加建议。最终版本是：

> 结论是本周只能上核心流程。两个选项，一是本周上核心流程、下周三补完整版；二是整体延到下周三，一步到位。我建议选第一个，因为客户那边可以先看到东西。你定。
>

**结果。** 对方回了两个字：选一。

**机制拆解。** 三个转变。

第一，他从拒绝对方（做不到）转向提供选项（做哪一部分）。这是从沟通维度升级到谈判维度的关键。

第二，他把对方的真实目标挖了出来。业务方要的是给客户交代，而不是非要本周上线完整版。

第三，他给了建议。给建议不是越权，而是在帮对方降低决策成本。

**可复制的做法。** 每次被顶回来，不要加强语气，而是走一遍三遍改写。同一件事换三次说法，通常第二次就有效果。

> 记录与验证：坚持两周错话本，统计高频错误类型。若某一类错误出现三次以上，就用三遍改写法集中练它一周。
>

## 板块9 · 避坑清单：这些话不要说
### 9_1 十二句高危表达
| 高危句 | 为什么危险 | 替代说法 |
| --- | --- | --- |
| 我是为你好 | 用动机代替理由，剥夺对方判断 | 我有个担心想跟你说，你听听看有没有道理 |
| 你懂我意思吗 | 把理解责任推给对方，暗含你没懂 | 我说清楚了吗，责任回到自己 |
| 你先冷静一下 | 否定对方情绪，火上浇油 | 我看你现在很急，我们先把事实列出来 |
| 这不怪我 | 防御姿态，对话立刻转为对峙 | 我这边的情况是这样 |
| 你为什么不这样做 | 说教，逼对方辩护 | 你觉得应该怎么做 |
| 我觉得如何如何，对专业人士说 | 用感受评价专业 | 从目标上看，这个方案能不能达到某个效果 |
| 大家有没有意见 | 逼出沉默，浪费最后一次发言机会 | 我这个判断可能漏了什么，谁能帮我挑一下 |
| 随便 | 把选择成本丢给对方 | 我倾向方案 A，你觉得呢 |
| 我一直都是这么做的 | 用惯性代替理由 | 之前这么做的原因是什么，现在情况变了，我建议 |
| 你应该如何如何 | 命令式，触发防御 | 如果是我，可能会这样做 |
| 这事很简单 | 贬低对方困难 | 我第一次做也卡住了，卡在哪里 |
| 算了，不说了 | 切断沟通，制造暗伤 | 我现在说得不够清楚，给我五分钟整理一下 |


### 9_2 三个结构性错误（比具体句子更致命）
**错误一，结论后置。** 讲了三分钟背景才说重点。听众在前三十秒就决定要不要听。

**错误二，只说感受不说事实。** "我觉得很不顺"无法被回应，"交付延迟了三天"才能被解决。

**错误三，一次性给太多选项。** 超过三个选项等于没有选项。给两个，并给出你的建议。

**为什么这三个更致命。** 因为具体句子可以事后补救，结构性错误会毁掉整段沟通。你可以在说错一句话之后道歉，但你无法在讲砸三分钟之后重来。

### 9_3 三种暗伤场景
| 场景 | 暗伤如何形成 | 预防 |
| --- | --- | --- |
| 好心提醒变成指手画脚 | 焦点在你该怎么改 | 焦点放在我的感受和我的建议 |
| 想安慰变成漠不关心 | 用否定情绪的方式安慰 | 用陪伴和具体帮助 |
| 想委婉变成暗藏心机 | 绕弯太多，对方反而觉得被算计 | 直接说结论，再解释原因 |


**第三种最值得警惕。** 委婉的初衷是减少冲击，但绕弯超过两圈之后，对方会开始猜测你的真实意图，而猜测的结果通常比真相更负面。

**判断绕弯是否过度的标准。** 如果你需要三句话才能说到核心，就已经过度了。正确做法是：先说结论，再解释原因。这样既直接又不粗暴。

> 记录与验证：把这张清单放在手边，一周内检查自己踩了几条。第二周的目标是把数量减半。注意只减最高频的那几条，不要试图一次改掉全部。
>

## 板块10 · 三十天练习计划与验证
### 10_1 三十天阶梯
| 阶段 | 天数 | 主题 | 每日动作，十分钟内 | 周末加练 |
| --- | --- | --- | --- | --- |
| 第一阶段 | 第一到第七天 | 识别维度 | 每天记录一次对话：属于哪一维，我用对了没 | 做一次十二句高危表达自查 |
| 第二阶段 | 第八到第十四天 | 沟通维度 | 每天用一次承认情绪或复述确认 | 用错话本复盘三次对话 |
| 第三阶段 | 第十五到第二十一天 | 说服维度 | 每天做一次"对方真正在意的是什么"的写句练习 | 用三遍改写法改一条常用语 |
| 第四阶段 | 第二十二到第二十七天 | 谈判与向上 | 每天用一次三选项表达：结论加 A 与 B 加建议 | 做一次完整的薪资或资源模拟谈判 |
| 第五阶段 | 第二十八到第三十天 | 演讲与复盘 | 每天出声讲一遍 PREP 结构 | 回看全部话术卡，统计达成率 |


**两条规则。**

**规则一，每天只练一个动作。** 不要在同一天既练复述又练三选项，那样两个都练不成。

**规则二，周末加练可以跳过，但每日动作不能连续跳过两天。** 连续两天中断，习惯链就断了。

### 10_2 每日三问（每天收尾用）
```latex
  第一问，今天哪一句话是我主动选的，而不是脱口而出的
  第二问，今天有没有一句话说完后想收回，写进错话本
  第三问，明天我要刻意用哪一条
```

**第一问的价值最大。** 因为它训练的是"在说话之前有零点五秒的停顿"。绝大多数说错的话，都是因为没有这零点五秒。

### 10_3 三十天验证表
| 指标 | 开始前基线 | 第十五天 | 第三十天 |
| --- | --- | --- | --- |
| 维度判断正确率，自己估算 |  |  |  |
| 返工率，同一事要说几次 |  |  |  |
| 对抗度，对方防御性回应次数每周 |  |  |  |
| 达成率，主动沟通拿到结果的次数每月 |  |  |  |
| 错话本累计条目 |  |  |  |


**判读方法见 0_5 的三个口径说明，这里只补两条观察经验。**

**第一条，看错话本的条目变化。** 前两周通常会增加，因为你开始注意到自己说错的话；第三周开始下降，因为你开始改。如果第三周还在增加，说明你只记录没练习，需要把 8_1 的三遍改写法加进来。

**第二条，看达成率的结构。** 同样是三次成功，如果三次都来自同一类场景，比如都是说服同事，说明你只打通了一维。真正的进步是五个维度各有一次成功，那才叫全息。

> 记录与验证：第一天填基线列，第十五天和第三十天各测一次。只比趋势，不看单点。
>
