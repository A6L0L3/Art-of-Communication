# 《非暴力沟通》·观察-感受-需要-请求沟通法笔记

> 一句话主旨：当语言不再带有评判与攻击，它就能成为连接彼此心灵的桥梁——把对话从"谁对谁错"的战场，变成"我需要什么、你需要什么"的协作桌。

## README · 导览

### README_1 这份笔记解决什么问题

这本书解决的是一个日常却致命的问题：我们习惯把"暴力"等同于拳脚，却忽视了言语上的指责、嘲讽、否定、说教、贴标签、拒不回应，同样是一种暴力——它摧毁的不是身体，而是人与人之间的信任与连接。

回顾一下今天的对话：

- 对伴侣："你怎么又把袜子扔地上！"（指责）
- 对孩子："你就知道玩手机！"（评判）
- 对同事："这方案写得什么玩意儿？"（嘲讽）
- 对自己："我真是个废物。"（自我攻击）

这些脱口而出的话，背后藏着同一种思维惯性：我们被教育去判断"对与错"，却从未被教过如何表达"感受与需要"。这份笔记把全书重构为可执行的"四步法 + 倾听 + 场景应用"体系，用于修复亲密关系、亲子沟通、职场协作，以及与自我的关系。

需要预先说明：非暴力沟通不是话术、不是谈判技巧、更不是让对方服从你的手段。它的目的是让双方的需要都被看见、被尊重，从而自发地选择合作，而非被迫妥协。把它当操纵工具，从第一天起就用错了。

### README_2 阅读路径

- 完整路径：按板块 1 至板块 6 顺序通读，先识别暴力沟通，再学四步法，再练倾听，最后落到场景。
- 急救路径：明天就要谈一件敏感的事 → 直接读板块 2、板块 3（四步法与万能句式），再用板块 6 的速查清单自检。
- 被攻击时路径：有人正在对你发火 → 读板块 4（倾听与"翻译"）。
- 自我攻击时路径：刚搞砸了某事正在自责 → 读板块 5（自我对话）。

### README_3 必须接受的前提

- 他人的言行不是我们感受的起因，我们自己的需要才是。
- 说"你让我……"时，对方听到的是指责；说"我需要……"时，对方听到的是脆弱与渴望。
- 请求被拒绝不等于失败——非暴力沟通的目标是理解，不是"得到想要的"。
- 你只能控制自己的表达方式；当你持续用非暴力沟通，对方迟早会被你的稳定所影响。
- 非暴力沟通是最坚定的表达方式：清晰地知道自己要什么、不要什么，同时尊重对方。真正的软弱是回避冲突、压抑自己。

### README_4 笔记记录方法

本书是强实践型读物，推荐"三色标记法 + 四步改写卡 + 问答式批注"组合。

三色标记法（重读时用）：

- 蓝色：可直接复用的句式、词汇表、清单（如万能句式、感受词汇表）。

四步改写卡（每次把暴力对话改写为四步后填写）：

| 字段 | 记录内容 |
| --- | --- |
| 日期/对象 | 何时、对谁 |

| 暴力类型 | 指责/评判/比较/回避责任/强人所难 |

## 板块1 · 为什么需要非暴力沟通

### 1_1 暴力不止于拳脚

我们习惯把"暴力"等同于肢体冲突，但卢森堡提醒我们：言语上的指责、嘲讽、否定、说教、贴标签、拒不回应，都是一种暴力。它摧毁的不是一个身体，而是人与人之间的信任与连接。

印度哲学家克里希那穆提曾说："不带评论的观察，是人类智慧的最高形式。"

### 1_2 我们为什么总在"暴力沟通"

- 对伴侣："你怎么又把袜子扔地上！"（指责）
- 对孩子："你就知道玩手机！"（评判）
- 对同事："这方案写得什么玩意儿？"（嘲讽）
- 对自己："我真是个废物。"（自我攻击）

这些脱口而出的话，背后往往藏着同一种思维惯性：我们被教育去判断"对与错"，却从未被教过如何表达"感受与需要"。

### 1_3 非暴力沟通的终极目标

非暴力沟通不是话术，不是谈判技巧，更不是让对方服从你的手段。它的目的是：让双方的需要都被看见、被尊重，从而自发地选择合作，而非被迫妥协。

### 1_4 四种常见的"暴力沟通"陷阱

| 陷阱 | 典型话术 | 问题本质 |
| --- | --- | --- |
| 道德评判 | "你太自私了""他是个混蛋" | 用自己的价值观给对方贴标签，制造对立 |
| 进行比较 | "你看人家孩子多争气" | 用比较制造羞耻感，摧毁自我价值 |
| 回避责任 | "我也没办法，是领导要求的" | 把原因推给外部，放弃选择的权利 |
| 强人所难 | "你必须这样做，否则……" | 命令、威胁、奖惩控制，剥夺对方自主权 |

自检标准：如果你说完一段话，对方的反应是防御、沉默或反击——大概率你踩了以上某个坑。

### 1_5 案例小故事：一句"你总是"引发的冷战

小周和女友同居半年。某个周一早晨，他看见玄关的袜子，脱口而出："你怎么又把袜子扔地上！"女友瞬间冷脸："你总是为这种小事凶我。"小周辩解："我哪里凶你？我这不是让你讲卫生吗？"两人冷战三天。回看时小周发现，"又"是评判（暗含"你一贯如此"），"总是"是比较性概括，而他的真实需要只是"我希望家里整洁，我累了想被体谅"。

启示：暴力沟通的可怕之处在于它披着"讲道理"的外衣。一句评判出口，对方听到的是攻击，本能进入防御；需要没被说出口，冷战就成了唯一的沟通方式。

### 1_6 落地练习：一周暴力语言观察日记

- 准备手机备忘录，连续 7 天，每天睡前记录：今天我说出口的评判/指责/比较/威胁，原话照抄。
- 每条后面标注踩了哪个陷阱（道德评判/进行比较/回避责任/强人所难）。
- 第 7 天统计：哪类陷阱最高频？对谁最高频？只观察，不改正——先提高觉察，再谈改变。

## 板块2 · 四步法之上篇：观察与感受

### 2_1 第一步：观察——只说事实，不加评判

关键原则：区分"观察"与"评论"。

| 评论（带评判） | 观察（纯事实） |
| --- | --- |
| 你总是迟到 | 这周三次会议你都迟到了 10 分钟 |
| 你从不关心我 | 最近一个月你没有主动给我打过电话 |
| 这孩子太懒了 | 他这周有三天没整理自己的房间 |

技巧：用"具体时间 + 具体行为 + 可验证"来描述。避免使用"总是、从不、经常、很少"这类模糊词。

### 2_2 第二步：感受——说情绪，不说想法

很多人分不清"感受"和"想法"。判断标准很简单：这句话是在描述内心情绪，还是在评价对方？

| 伪装成感受的"想法" | 真实的感受 |
| --- | --- |
| 我觉得你不在乎我 | 你没回我消息，我感到失落和担心 |
| 我觉得这方案很烂 | 看到数据部分缺失，我感到焦虑 |
| 我觉得自己很没用 | 搞砸了这次汇报，我感到沮丧 |

常用感受词汇表：

- 难过类：伤心、沮丧、失落、孤独、委屈、尴尬
- 愤怒类：生气、恼火、厌烦、不耐烦
- 恐惧类：害怕、担心、焦虑、紧张、不安
- 愉悦类：开心、欣慰、满足、感激、放松、温暖

### 2_3 案例小故事：从"你从不关心我"到"我感到失落"

小琳的男友连续两周加班，纪念日也忘了。她编辑了一条消息："你从来不关心我，你心里只有工作。"发出去之前，她改成四步第一、二步："这周你有四个晚上十点以后才回家，纪念日也忘了（观察）。我感到失落和担心（感受）。"发出去十分钟，男友回电话："对不起，这周项目上线，我忽略了你的感受。今晚我早点回来，我们补过好不好？"

启示：同样的诉求，"你从不关心我"让对方启动防御（翻旧账、反驳），"我感到失落"让对方启动共情（道歉、补偿）。观察把矛头从人格转到事实，感受把攻击换成示弱——而示弱在亲密关系里恰恰是最有力的表达。

### 2_4 落地练习：观察-感受双步训练

- 第 1 步训练（观察）：本周每次想开口批评人时，先在心里把评价句改写成"具体时间 + 具体行为"。例如"你又拖了" → "这次比约定时间晚了两天"。
- 第 2 步训练（感受）：每天花 2 分钟记录"今天我有什么感受"，强制使用四类情绪词汇（难过/愤怒/恐惧/愉悦）各至少一次。坚持一周，你会发现自己对情绪的觉察力显著提升。
- 检验标准：写完后问自己"这句话拿去法庭能当证据吗？"——观察必须经得起证据检验。

## 板块3 · 四步法之下篇：需要与请求

### 3_1 第三步：需要——找到感受背后的根源

这是非暴力沟通最反直觉、也最有力的一步。卢森堡的核心洞见是：他人的言行不是我们感受的起因，我们自己的需要才是。

| 表面归因（指责对方） | 真实需要（向内看） |
| --- | --- |
| "你迟到让我生气" | "我需要守时，需要被尊重" |
| "你吼我让我伤心" | "我需要安全感，需要温柔对待" |
| "孩子不学习让我焦虑" | "我需要确认孩子在为未来负责" |

为什么这一步至关重要？当你说"你让我……"时，对方听到的是指责，本能反应是辩解或反击；而当你说"我需要……"时，对方听到的是你内心的脆弱与渴望，更容易产生共情。

常见需要清单：

- 安全感、稳定性、归属感
- 被理解、被倾听、被尊重
- 自主性、成就感、成长
- 亲密、陪伴、爱与被爱

### 3_2 第四步：请求——具体、正向、可执行

请求不等于命令。区分标准只有一个：当对方说"不"时，你的反应是什么？

- 如果尊重对方的选择 → 这是请求。
- 如果愤怒、威胁、冷暴力 → 这是命令。

| 维度 | 糟糕表达 | 好的请求 |
| --- | --- | --- |
| 具体 | "你能不能上点心？" | "明天开会前能把报告发我看一下吗？" |
| 正向 | "别再打游戏了！" | "今晚能不能陪我聊半小时天？" |
| 可执行 | "你要对我好一点！" | "周末我们一起去爬山好吗？" |
| 留余地 | "你必须听我的！" | "你愿意考虑一下吗？" |

万能句式（可根据场景灵活调整顺序）：

"当我看到/听到 ____（观察），我感到 ____（感受），因为我需要/看重 ____（需要），你是否愿意 ____（请求）？"

### 3_3 案例小故事：一次请求的转化实验

老陈想让儿子少玩游戏。原来的说法："你别老玩手机了！你能不能上点心？"儿子充耳不闻。改用四步："这周你有四个晚上玩到十二点以后（观察），我有些担心（感受），因为我需要你保证睡眠、对明天有精神（需要），你是否愿意把这周的游戏时间改到十点前（请求）？"儿子犹豫了一下，说："那周末能多玩一小时吗？"老陈点头。谈判第一次真正发生——因为请求留了余地，儿子有了说"不"的空间，反而给出了承诺。

启示：命令只能换来服从或反抗，请求才能换来协商。当对方发现"说不也不会被惩罚"，他才有可能说出真实的想法——而真实想法，正是合作的起点。

### 3_4 落地练习：万能句式填空训练

- 找一个本周真实的小冲突，按万能句式写一段完整四步，念出声，感受语气差异。
- 改写练习：把以下三句话各改写成四步——
  1. "你怎么又迟到" → 观察：这次比约定晚了 20 分钟；感受：我有些着急；需要：我需要守时和确定感；请求：下次如果不能准时到，能提前发消息告诉我吗？
  2. "你根本不听我说话" → 观察：刚才我说话时你在看手机；感受：我感到被忽略；需要：我需要被倾听；请求：接下来十分钟，你能看着我听我说完吗？
  3. "这方案不行" → 观察：方案的数据部分有三个来源没标；感受：我有些担心；需要：我需要经得起客户追问；请求：能在这两处补上来源吗？
- 自检四问（开口前 3 秒过一遍）：我说的是事实吗？我说的是情绪吗？我说清楚自己要什么了吗？我允许对方说"不"吗？

## 板块4 · 倾听：沟通的另一半

### 4_1 全身心倾听的要点

非暴力沟通不是"我表达得漂亮"就结束了。真正的沟通是双向的——倾听占了一半以上的权重。

1. 放下自己的议程：不要在对方说话时构思反驳，先把注意力完全给对方。
2. 听"冰山之下"：对方表面在说"你总是……"，底下藏的是"我感到……，因为我需要……"。
3. 用复述确认："你感到很委屈，是因为你需要被公平对待，对吗？"
4. 沉默也是礼物：有时对方只需要你安静地陪着，不需要你给建议。

### 4_2 当对方在"暴力表达"时怎么办

这是最考验人的场景。卢森堡给出的答案是：不要反击，不要辩解，去翻译。

对方说："你就是个不负责任的人！"

翻译为："你感到失望和愤怒（感受），因为你希望我能更可靠地履行承诺（需要）。"

当你用这种方式回应时，奇迹往往会发生——对方的攻击性会迅速下降，因为他被听见了。

### 4_3 案例小故事：难民营里的对话

卢森堡在巴勒斯坦难民营做培训时，一位愤怒的听众站起来大喊："你们美国人都是杀人犯！"现场一片死寂。卢森堡没有反驳，而是说："听起来，你非常愤怒（感受），因为你希望你们民族的安全能得到保障（需要）。你愿意告诉我更多你的经历吗？"那位听众愣了一下，然后开始讲述自己的故事。最后，他邀请卢森堡去家里吃饭。

启示：这句回应没有辩解一个字，却完成了三件事——接住了他的情绪（愤怒），翻译出了他的需要（安全），给出了出口（请讲述）。攻击性语言从来不是目的，而是需要的畸形表达；翻译需要，就是拆除引信。

### 4_4 落地练习：倾听翻译训练

- 翻译练习：本周遇到一次指责/抱怨时，在心里完成翻译，然后说出确认句："你感到很____，是因为你需要____，对吗？"
- 常见翻译对照（提前预习）：

| 对方的暴力表达 | 冰山之下的翻译 |
| --- | --- |
| "你从来不管这个家！" | "你感到孤单和疲惫，你需要被分担、被看见" |
| "你根本不爱我了！" | "你感到恐慌，你需要确认自己还被在乎" |
| "这什么破方案！" | "你感到焦虑，你需要这个项目不出岔子" |
| "别理我！" | "你感到混乱，你需要空间自己整理" |

- 红线提醒：翻译不是认同所有指责的事实部分，而是承认情绪与需要。如果对方持续人身攻击，你可以离开——倾听不等于接受虐待。

## 板块5 · 扩展应用：亲密关系、亲子、职场与自我对话

### 5_1 亲密关系

- 用"我需要陪伴"替代"你根本不在乎我"。
- 用"我看到你今天主动洗碗了，我很开心"替代"你终于干了点人事"。
- 核心：让伴侣感受到"被需要"而非"被要求"。

### 5_2 亲子教育

- 不用奖惩控制孩子，而是帮孩子连接自己的需要。
- 例：孩子打人 → "我看到你打了弟弟（观察），你当时感到什么？（引导感受）你想要什么？（引导需要）下次可以怎么做？（引导请求）"
- 核心：培养孩子的内在驱动力，而非对外在奖惩的依赖。

### 5_3 职场沟通

- 反馈不是批评："这个方案的数据部分（观察），让我有些担心（感受），因为客户很看重准确性（需要），能否再核对一遍？（请求）"
- 拒绝不是得罪人："我很想帮你（感受），但我目前手头有三个紧急项目（观察），我需要保证质量（需要），这次可能帮不了，抱歉。"

### 5_4 自我对话（爱自己）

这是最容易被忽略、却最治愈的一环。

| 自我暴力 | 自我非暴力沟通 |
| --- | --- |
| "我真是个废物" | "这次没做好，我感到沮丧，因为我需要成就感。下次可以怎么调整？" |
| "我怎么这么胖" | "我对体重不满意，因为我需要健康和活力。我愿意为自己做些什么？" |
| "我应该更努力" | "我感到焦虑，因为我需要安全感。我愿意给自己一些鼓励。" |

每当你想骂自己的时候，试着用非暴力沟通和自己对话一次——你会发现，自责不会让你变好，但自我关怀会。

### 5_5 案例小故事：一次职场反馈的重写

项目经理大刘对下属小张的方案不满，原话是："这方案写的什么玩意儿？数据呢？"小张当场沉默，之后三天躲着他走。大刘改用四步："这个方案里第三部分的数据（观察），让我有些担心（感受），因为客户下周来会重点核对准确性（需要），能否今晚之前把三个来源补上（请求）？"小张当晚就补好了，还主动约他过了一遍框架。

启示：职场反馈的杀伤力往往不在内容而在包装。"什么玩意儿"摧毁的是小张的主动性；四步法则把"我不满意你"转成"这件事有个标准要达成"，后者给出路，前者只给出局。

## 板块6 · 实践障碍、金句与速查工具

### 6_1 实践中的常见障碍与应对

**障碍 1："这太绕了，说不出来怎么办？"**

非暴力沟通不是让你每次对话都走完四步。先从一个要素开始练——比如这周只练"说感受"。熟练了再加下一个。

**障碍 2："对方不按套路出牌怎么办？"**

你只能控制自己的表达方式，对方的反应不在你手里。但当你持续用非暴力沟通，对方迟早会被你的稳定所影响。

**障碍 3："我表达了需要，对方还是拒绝怎么办？"**

请求被拒绝不等于失败。非暴力沟通的目标是理解，不是"得到想要的"。你可以继续探索："你拒绝是因为你也有需要吗？愿意告诉我吗？"

**障碍 4："会不会显得太软弱？"**

恰恰相反。非暴力沟通是最坚定的表达方式——它要求你清晰地知道自己要什么、不要什么，同时尊重对方。真正的软弱是回避冲突、压抑自己。

### 6_2 案例小故事：被拒绝之后

小杨用四步向朋友借一笔钱周转，朋友拒绝了。他第一反应是受伤和恼怒，差点说出"你真不够意思"。他忍住了，改用倾听："你拒绝，是因为你也有需要吗？愿意告诉我吗？"朋友松口："我最近也在凑首付，借你我就断了现金流。"小杨说："我理解了，谢谢你告诉我真实情况。"两人关系反而比借之前更近。半年后朋友主动问他还需不需要。

启示：被拒绝时最容易滑回暴力沟通，因为"被拒绝"刺痛的是被认可的需要。此时恰恰最需要区分：拒绝的是请求，不是你这个人。能接住拒绝的关系，才有第二次开口的余地。

### 6_3 全书金句摘录

1. "如果我知道自己想要什么，我就能得到它。"——但前提是，你得先知道自己想要什么。
2. "我们不是生来就会用非暴力沟通的，我们是被迫学会用暴力沟通的。"
3. "一旦人们开始谈论需要，而非互相指责，合作就自然发生了。"
4. 表达感激时，也用四要素：我看到你做了什么（观察），我感受到什么（感受），因为这满足了我的什么需要（需要）。——这样对方才知道自己被感谢的具体原因。
5. "非暴力沟通的精髓，在于对这四个要素的觉察，而不在于使用什么字眼。"

### 6_4 总结：一句话记住这本书

非暴力沟通的本质，是把对话从"谁对谁错"的战场，变成"我需要什么、你需要什么"的协作桌。它教我们的不是怎么赢，而是怎么连接——连接他人，也连接自己。

### 6_5 速查清单：非暴力沟通四步自检表

下次开口前，花 3 秒过一遍：

- [ ] 观察：我说的是事实吗？有没有夹带评判？
- [ ] 感受：我说的是情绪吗？还是在变相指责？
- [ ] 需要：我有没有说清楚自己真正想要的是什么？
- [ ] 请求：我提的是具体、正向、可执行的要求吗？我允许对方说"不"吗？

### 6_6 落地练习：30 天渐进训练计划

- 第 1 周：只练"观察"——把所有评判句改写成事实句，每天记录 3 条。
- 第 2 周：加入"感受"——每天 2 分钟情绪记录，用满四类情绪词汇。
- 第 3 周：加入"需要"——每次有情绪时问自己"我真正需要的是什么"，写下来。
- 第 4 周：完整四步——在本周一次真实冲突中完整使用万能句式，并填写四步改写卡。
- 全程保留：每周一次小复盘，对照 6_5 速查清单自测完成度。
