# 沟通的艺术（**`Art-of-Communication`**）

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/deed.zh)

> 一个把「书、影、话术」拆成可执行动作的开源笔记库。

本仓库不是书评影评合集，而是一套**以交付结果为目标的行动手册**：每一篇笔记都拆成若干板块，板块内再拆成「这是什么 → 为什么有效 → 怎么做 → 怎么验证 → 出错了怎么办」，读完能照着做，而不是读完只剩一句"很有道理"。

## 📖 分区说明

### 读书笔记

主题覆盖社会心理、沟通表达、亲密关系、个人成长、文学叙事五个方向。

- **表达与边界**：《非暴力沟通》《好好说话》《身体语言密码》《掌控边界》《内向者沟通圣经》《倾听孩子》。
- **亲密关系与情绪**：《爱的冲突》《爱的艺术》《幸福的婚姻》《幸福婚姻的七个原则》《依恋与亲密关系》《亲密关系》《亲密关系Ⅱ：无拘无束的关系》《情绪勒索》《煤气灯效应》《爱自己，和谁结婚都一样》。
- **自我认知与生命议题**：《被讨厌的勇气》《幸福的勇气》《活出生命的意义》《自卑与超越》《第二性》《理解人性》《也许你该找个人聊聊》《写给女孩子的幸福忠告》。
- **文学与人生叙事**：《围城》《野兽绅士》《他知道风从哪个方向来》《小孩的哲学是大人的解药：丰子恺的人生漫笔》《回家的诱惑》。
- **说服与影响力**：《人性的弱点》。

每一篇独立成文件，不做跨书合并。

### 观影笔记

以关系发展的几个阶段观察影片：**初见**（《怦然心动》《你的名字。》《爱在黎明破晓前》《喜欢·你》）、**错过**（《后来的我们》《从你的全世界路过》《前任攻略》《致我们终将逝去的青春》《现在去见你》）、**相守**（《七月与安生》《北京遇上西雅图》《时空恋旅人》《恋恋笔记本》）、**暗面**（《花束般的恋爱》《无耻之徒》）。另有《恋空》从叙事结构与镜头语法角度做文本细读。每一部独立成文件。

### 主题手册

跨书跨影的综合手册，把分散技巧拧成一条完整动线：《超级演说家》（从底层认知到四阶段训练到控场复盘的表达训练体系）·《贵气感养成系统手册》（气场与分寸）·《路过你的全世界》（关系与叙事）·《酒桌摇骰子必应攻略》（社交博弈）。

> 上述方向与阶段是本仓库对内容的**编排视角**，用于给出阅读顺序建议；仓库中每一篇都是独立文件，未额外打标签或建分类索引页。

## 🧭 笔记体例

每篇笔记都是自足结构，格式统一，打开即用：

```
# 《作品名》· 一句话定位
## README · 导读与导航   ← 仅主题手册有此段
## 板块0 · README      ← 这份笔记解决什么问题 / 阅读路径 / 必须接受的前提
                        笔记记录方法 / 效果验证 / 与其他笔记的搭配
## 板块1 · 主题        ← ### 1_1 / 1_2 …… 具体小节
## 板块2 · 主题
……
```

- 读书与观影笔记的板块0固定六节（0_1 到 0_6）：这份笔记解决什么问题、阅读路径、必须接受的前提、**各类场景的笔记记录方法**、**实用验证方式**、与其他笔记的搭配；四部主题手册的板块0为「学习路径建议」，包含路径总览、水平自测、训练节奏、常见误区与精通标准。
- **每篇笔记都配案例小节**：读书与观影笔记统一为「案例小故事」小节，主题手册为「案例」小节，说明这一步在什么场合用、会出现什么反应。
- **图示不依赖任何图片文件或外链**：全库 0 张外链图片、0 处图片语法。图示一律以 ASCII 字符图（```plain 代码块）、LaTeX 公式块或缩进文本块呈现，在 Obsidian、Typora、语雀、VS Code、GitHub 中均可直接显示，离线也不会裂图。
- 时间以相对表述为主（第 1 周 / 30 天 / 3 个月 / 21 天），训练计划不写死年份，便于任何时候打开都能执行；仅在陈述影片、导演等史实时标注具体年份。
- 术语与论点均出自原著/原片公开信息，笔记本身是**再加工的方法论**，不替代原始作品。
